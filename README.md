# JioSaavn Homepage Recreation

A dedicated frontend recreation of the JioSaavn music streaming homepage, built entirely from scratch using only standard HTML and basic CSS properties. This project serves as a focused hands-on exercise to practice implementing the native HTML audio element while mastering fundamental layout techniques. Without relying on any scripts, this build explores how to structure a complex media platform interface using traditional web design methods.

## ✨ Features & Design

Native Audio Integration: Implements the built-in HTML audio element to explore native media playback capabilities within a static environment.

Classic Layout Techniques: Built strictly using fundamental styling controls, utilizing classic properties like margin, padding, and float to arrange interface elements.

Structured Interface: Features a sleek, light color scheme inspired by real-world streaming platforms, complete with curated playlist sections, trending album showcases, and organized media components like side navigation menus and song lists.

## 🛠️ Tech Stack

Structure: Standard HTML5

Styling: Basic CSS (utilizing core properties such as margin, padding, float, and css position)

Media: Native HTML <audio> tag
